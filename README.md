# My Portfolio

A modern, animated developer portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion. It highlights projects, experience, and contact options with a polished UI and responsive layout.

## Highlights

- Smooth section navigation with a fixed navbar
- Animated hero and sections using Framer Motion
- Data-driven projects and experience timeline
- Responsive layout for mobile and desktop
- Themed background with layered visual effects

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Getting Started

### Prerequisites

- Node.js 18+ (recommended)
- npm or pnpm

### Install

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open the URL shown in the terminal to view the site.

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Project Structure

public/
src/
  components/
  data/
  App.tsx
  index.css
  main.tsx

## Customization

- Update content in `src/data/portfolioData.ts`.
- Tweak layout and sections in `src/App.tsx`.
- Adjust styling in `src/index.css` and Tailwind classes.
- Replace images and icons in `public/` and `src/assets/`.

## Scripts

- `npm run dev` - Start dev server
- `npm run build` - Production build
- `npm run preview` - Preview build

## Deployment

This project can be deployed on Vercel, Netlify, GitHub Pages, or any static hosting provider. Use the `npm run build` output in `dist/`.
